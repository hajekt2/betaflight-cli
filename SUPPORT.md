# Support

Use [GitHub Issues](https://github.com/hajekt2/betaflight-cli/issues) for reproducible bugs and focused feature requests.
Use GitHub Discussions for usage questions if Discussions are enabled for the repository.

Before opening an issue, run `betaflight-cli version`, `betaflight-cli doctor`, and the failing command with `--verbose` when it is safe to do so.
Remove serial numbers, names, bind data, and other private configuration before posting output.

The project currently supports official Betaflight 2025.12.x and newer over USB serial on Windows, macOS, and Linux.
Older Betaflight releases, forks, wireless transports, and browser bridges are outside the supported scope.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
For flight-safety emergencies, stop using the tool and follow the aircraft and flight-controller manufacturer's safety procedures.
